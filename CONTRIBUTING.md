# Contributing

Thank you for helping improve PAH Broken Link Checker.

## Before Opening an Issue

1. Re-run the audit to rule out a temporary network failure.
2. Open the destination in a normal browser.
3. Check whether the site requires login, blocks automated requests, or applies rate limits.
4. Remove credentials, private URLs, personal data, and other sensitive information.

## Bug Reports

A useful bug report includes:

- The public URL tested
- The classification shown by the tool
- The result observed in a browser
- The approximate time of the test
- Reproduction steps
- A sanitized screenshot, when helpful

## Feature Requests

Explain the problem first, then describe the proposed improvement and how it would help site owners, developers, or SEO professionals.

## Scope

This repository currently accepts documentation improvements, reproducible bug reports, and product suggestions. The production source code is not published here, so code pull requests may be closed unless a maintainer specifically requests one.

## Conduct

Be respectful, factual, and constructive. Do not use the issue tracker for spam, paid-link offers, unrelated promotion, or disclosure of sensitive information.
