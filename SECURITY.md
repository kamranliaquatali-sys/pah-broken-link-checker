# Security Policy

## Supported Service

Security reports should relate to the live PAH Broken Link Checker at:

https://proarticleshub.com/broken-link-checker/

## Reporting a Vulnerability

Do **not** publish credentials, private endpoints, personal data, or exploit details in a public GitHub issue.

Send a concise private report through the contact page:

https://proarticleshub.com/contact-us/

Include:

- A description of the issue
- Reproduction steps
- The affected URL or component
- Potential impact
- A sanitized proof of concept, when appropriate

Please allow reasonable time for investigation before sharing details publicly.

## Ordinary Scan Results

A link reported as blocked, timed out, rate limited, or temporarily unavailable is not necessarily a security vulnerability. For ordinary false positives and classification problems, use the public bug-report template.
